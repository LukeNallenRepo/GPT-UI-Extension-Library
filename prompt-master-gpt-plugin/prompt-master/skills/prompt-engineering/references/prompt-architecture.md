# Prompt architecture reference

Use the following fields selectively for complex assignments:

- Role and objective
- Context and source of truth
- Scope and exclusions
- Constraints and permissions
- Inputs and dependencies
- Method and decision rules
- Deliverables and output format
- Acceptance criteria and verification
- Uncertainty and conflict handling
- Handoff and reporting

The prompt must be self-contained. Identify facts, assumptions, and unknowns separately. Name files, paths, tools, versions, or systems only when supplied or verified. Do not add a recipient or execution dependency that the user has not selected or that the available context does not establish.
