# Prompt Master

Prompt Master is a standalone prompt-engineering plugin for ChatGPT. It interprets user intent, preserves requirements and constraints, and produces clear prompts or self-contained task briefs for AI assistants, agents, tools, developers, and human operators.

## Included capability

The `prompt-engineering` skill provides request interpretation, context handling, requirement specification, prompt architecture, ambiguity resolution, role-aware agent instructions, handoff design, and delivery validation.

## Independence

Prompt Master does not require A.I Master or any other external toolkit. It can prepare instructions for a downstream system, but it does not claim to execute work through systems that are not connected or available.

## Installation

Install the private plugin through the ChatGPT plugin interface. Invoke Prompt Master for prompt creation, refinement, evaluation, or task-brief generation. The skill is configured for implicit invocation when relevant.

## Workflow

`USER → PROMPT MASTER → PROCESSING → DELIVERY`

The status and gate are rendered as text according to the host's supported presentation. A skill cannot guarantee a particular border or text colour in every client.
